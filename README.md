💳 QR BOX PAY — BLACK ELITE EDITION
Custom PromptPay QR Studio & Payment Layout Generator
เว็บไซต์สำหรับสร้างและตกแต่ง QR Code PromptPay ในสไตล์ Black & Red Elite Edition สุดหรู ออกแบบมาเพื่อร้านค้า, ฟรีแลนซ์, และผู้ใช้งานทั่วไปที่ต้องการสร้างการ์ดสแกนชำระเงินที่สวยงาม เป็นระเบียบ มีเอกลักษณ์ พร้อมฟังก์ชันคำนวณภาษี VAT, ส่วนลด, บันทึกประวัติ และจัดวางเลย์เอาต์ได้ตามต้องการ
✨ ฟีเจอร์หลัก (Key Features)
￼ 🖤 Black Elite UI Design: ธีมสีดำ-แดงสไตล์พรีเมียม สบายตา ตอบโจทย์การใช้งานยุคใหม่ พร้อมฟอนต์ Google Fonts (Prompt & Sarabun)
￼ 📲 Dynamic PromptPay QR Generation: สร้าง QR Code มาตรฐาน PromptPay จากเบอร์โทรศัพท์ หรือเลขบัตรประชาชน/เลขผู้เสียภาษี (รองรับทั้งแบบระบุยอดเงินและไม่ระบุยอดเงิน)
￼ 🧮 Advanced Amount Calculator: ระบบคำนวณยอดเงินรวมอัตโนมัติ คำนวณภาษี VAT (7%) และส่วนลดท้ายบิล พร้อมปุ่มตัวเลือกยอดเงินด่วน (Quick Amount)
￼ ✍️ Custom Caption Note: สามารถกำหนดข้อความหมายเหตุหรือข้อความขอบคุณท้ายบัตรได้ตามต้องการ
￼ 📐 Layout Studio Customizer: ปรับเลย์เอาต์ตำแหน่งของ QR Code ได้แบบเรียลไทม์ ทั้ง ขวา, ซ้าย, บน, และล่าง
￼ 🖥️ Fullscreen Modal Display: โหมดแสดงผลเต็มหน้าจอสำหรับตั้งโชว์หน้าร้านค้าหรือหน้าจอโทรศัพท์/แท็บเล็ต โดยแสดงผลเลย์เอาต์ตรงตามที่ตั้งค่าไว้
￼ 📜 Transaction History: บันทึกประวัติการสร้าง QR Code พร้อมระบบค้นหา (Search) และเรียกคืนข้อมูลกลับมาใช้งานซ้ำได้ทันที
￼ ⭐ Saved Presets: บันทึกข้อมูลบัญชีและข้อความที่ใช้บ่อยเป็นรายการโปรด เพื่อลดเวลาในการพิมพ์ซ้ำ
￼ 🖼️ Card Export & Download: ดาวน์โหลดบัตร QR Code ออกมาเป็นไฟล์ภาพ PNG คุณภาพสูง นำไปพิมพ์หรือส่งให้ลูกค้าได้ทันที
￼ 📱 Fully Responsive Design: รองรับการแสดงผลทุกอุปกรณ์ ไม่ว่าจะเป็นสมาร์ตโฟน แท็บเล็ต หรือคอมพิวเตอร์เดสก์ท็อป
🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
￼ Frontend: HTML5, CSS3, JavaScript (ES6+)
￼ CSS Framework: Tailwind CSS CDN
￼ Typography: Google Fonts (Prompt & Sarabun)
￼ QR Code Engine: QRious Library
￼ Icons: Font Awesome 6
￼ Backend Service (Optional): Google Apps Script (Code.gs) สำหรับเชื่อมต่อ Google Sheets Database

📖 ขั้นตอนการใช้งานระบบ (User Guide)
1. กรอกข้อมูลผู้รับเงิน:
￼ ระบุหมายเลขพร้อมเพย์ (เบอร์โทรศัพท์ 10 หลัก หรือ เลขบัตรประชาชน/ผู้เสียภาษี 13 หลัก)
￼ กรอกชื่อบัญชี / ชื่อร้านค้า
2. ระบุยอดเงิน (คำนวณภาษี & ส่วนลด):
￼ พิมพ์ยอดเงินฐาน เลือกรวม VAT 7% หรือใส่ส่วนลด ระบบจะคำนวณยอดชำระสุทธิให้อัตโนมัติ (หรือกดปุ่ม Quick Amount 100, 200, 500, 1,000 ฿)
3. เลือกเลย์เอาต์ตำแหน่ง QR:
￼ เลือกตำแหน่ง QR Code บนการ์ด ได้แก่ ขวา, ซ้าย, บน, หรือ ล่าง
4. ตรวจสอบพรีวิวและดาวน์โหลด:
￼ ตรวจสอบบัตรในส่วนการ์ดตัวอย่าง
￼ กดปุ่ม "แสดงเต็มจอ" เพื่อนำไปโชว์หน้าร้าน หรือกด "ดาวน์โหลดรูป" เพื่อเซฟไฟล์ภาพ PNG ไปใช้งาน
🌐 การเผยแพร่เว็บไซต์ (Deployment)
สามารถนำโปรเจกต์นี้ขึ้นออนไลน์ได้ฟรีผ่านบริการ Web Hosting ยอดนิยม:
￼ GitHub Pages:
1. Push โค้ดขึ้น Repository บน GitHub
2. ไปที่ ⁠Settings⁠ > ⁠Pages⁠
3. เลือก Branch เป็น ⁠main⁠ และโฟลเดอร์ ⁠/root⁠ จากนั้นกด ⁠Save⁠
￼ Vercel / Netlify:
1. Import Repository จาก GitHub
2. ตั้งค่า Root Directory แล้วกด ⁠Deploy⁠ ได้ทันที
⚠️ ข้อจำกัดและความปลอดภัย (Limitations & Security Notes)
1. In-Memory Storage: ในเวอร์ชัน Frontend เดี่ยว (Client-side) ประวัติการสร้างและรายการโปรดจะถูกเก็บในหน่วยความจำชั่วคราว หากรีโหลดหน้าเว็บ ข้อมูลอาจรีเซ็ต (สามารถเชื่อมต่อกับ ⁠Code.gs⁠ เพื่อบันทึกลง Google Sheets ได้)
2. PromptPay Validation: ควรทดสอบการสแกน QR Code ที่สร้างขึ้นด้วยแอปพลิเคชันธนาคารจริงก่อนนำไปแปะหน้าร้านหรือส่งให้ลูกค้าชำระเงิน
3. No Payment Verification: หน้าจอ QR Code และการ์ดสแกนใช้สำหรับอำนวยความสะดวกในการโอนเงินเท่านั้น ไม่ใช่การยืนยันว่าได้รับเงินแล้ว ผู้รับเงินต้องตรวจสอบสลิปและยอดเงินในบัญชีธนาคารทุกครั้ง
4. Tax & VAT Disclaimer: ฟังก์ชันคำนวณ VAT 7% และส่วนลดเป็นเพียงเครื่องมือคำนวณเบื้องต้นสำหรับการแสดงผลบนการ์ด ไม่สามารถใช้แทนใบกำกับภาษีเต็มรูปแบบตามกฎหมายได้
5. Internet Connection Required: ตัวระบบดึงไลบรารีและฟอนต์ผ่าน CDN จึงจำเป็นต้องเชื่อมต่ออินเทอร์เน็ตระหว่างใช้งาน
